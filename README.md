POLÍTICA DE PRIVACIDAD DE Equipos y Componentes
Última actualización: 9 de noviembre de 2026
Heber Perez, ("nosotros") opera la aplicación móvil Equipos y Componentes (en adelante, la "Aplicación"). Esta página le informa sobre nuestras políticas relativas a la recopilación, uso y divulgación de datos personales cuando utiliza nuestra Aplicación.
1. Recopilación y Uso de la Información
Nuestra Aplicación está diseñada para funcionar principalmente de forma local y sin conexión (Offline). Almacenamos la base de datos de equipos y componentes directamente en el almacenamiento interno de su dispositivo móvil.
Para habilitar características avanzadas de la Aplicación, se realizan únicamente las siguientes conexiones a internet:
• Descarga de Catálogo/Base de Datos: La Aplicación se conecta a repositorios públicos de GitHub para descargar especificaciones técnicas actualizadas de equipos y componentes. Esta acción es de solo lectura y no recopila información personal.
• Copias de Seguridad (Backup) a Demanda en Cuenta Propia: Si el usuario lo solicita explícitamente, la Aplicación transmitirá los datos locales de sus equipos y componentes editados directamente hacia la cuenta personal de GitHub del propio usuario.
2. Credenciales y Tokens de Autenticación
Para realizar las copias de seguridad, la Aplicación contiene un Token GitHub de mi pertenencia.
• Estas credenciales se almacenan de forma estrictamente local y cifrada en el dispositivo del usuario.
• Nosotros nunca recopilamos, visualizamos, ni almacenamos sus credenciales de GitHub en servidores externos.
3. Compartición de Datos con Terceros
Nosotros no compartimos ni vendemos sus datos con terceras empresas, redes de anuncios o agencias de analítica. La transferencia de datos de respaldo se realiza exclusivamente entre el dispositivo del usuario y el almacenamiento personal de su cuenta de GitHub.
4. Seguridad de los Datos
La seguridad de sus datos es nuestra prioridad. Toda transmisión de datos hacia GitHub se realiza mediante protocolos seguros y cifrados (HTTPS). El usuario es el único responsable de la custodia de los archivos respaldados dentro de GitHub.
5. Eliminación de Datos
Dado que el control de la información es local y del usuario:
• Datos locales: Puede eliminarlos por completo desinstalando la Aplicación o borrando los datos de almacenamiento desde la configuración de Android.
• Copias de seguridad: Al estar alojadas en mi cuenta de GitHub, solo basta comunicarse al email heberperez1984@gmail.com y los datos seran eliminados del repositorio.
